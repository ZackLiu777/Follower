# Alpha Spec

## 1. 版本目标

Alpha 版本的目标是验证一个最小可用闭环：

- 用户登录账号
- 拉取基础数据
- 本地保存
- 展示基础统计
- 展示历史趋势
- 支持本地导出
- 支持两套 UI 风格
- 保留 Premium 扩展接口

Alpha 不追求完整商业化能力，也不实现全部高级分析功能。

## 2. 产品定位

这是一款本地优先的 Instagram / TikTok 数据跟踪与分析应用。

核心卖点：

- 本地保存
- 不上传云端
- 隐私优先
- 数据可视化
- 简洁直观
- 基础版可长期使用
- Premium 只是在基础版上增强分析能力

## 3. Alpha 版范围

### 3.1 必做功能

- 登录与账号绑定
- 基础数据同步
- 基础统计展示
- 历史趋势展示
- 本地持久化
- 数据导出
- 基础设置页
- 主题切换
- 免费试用计时逻辑

### 3.2 预留但不强制实现的功能

- 趋势预测
- 粉丝增长预测
- 活跃度分析
- 留存率分析
- 粉丝来源地域分布
- 互动质量评分
- 长期趋势对比
- CSV / Excel 导出增强版
- 本地 AI 分析
- 强加密与多设备同步

## 4. 免费试用规则

- App 首次打开后进入试用状态。
- 试用时长为 1 小时。
- 试用期间开放 Premium 的全部入口。
- 试用结束后不封锁 App。
- 试用结束后仅保留基础版功能。
- Premium 功能按钮仍可见，但需展示受限状态与升级入口。

## 5. 数据原则

- 所有用户数据默认仅保存在本地。
- 不向任何 cloud 上传用户数据。
- 所有导出操作都必须由用户主动触发。
- 基础版只依赖本地数据与已同步数据。
- Event / Snapshot / Metric 三层模型必须保留。

## 6. 功能清单

### 6.1 基础数据统计
展示：

- 粉丝数
- 关注数
- 帖子数
- 基础互动数
- 基础访问量

### 6.2 互动统计
展示：

- 评论数
- 点赞数
- 分享数
- 互动率

### 6.3 历史趋势
展示：

- 日趋势
- 周趋势
- 月趋势
- 增长与下降变化

### 6.4 数据导出
支持：

- JSON 导出
- CSV 导出

### 6.5 主题切换
支持：

- Apple Native
- Instagram Style

### 6.6 设置页
支持：

- 试用状态查看
- 数据存储说明
- 隐私政策入口
- 导出入口
- 主题切换

## 7. UI 要求

- 使用 SwiftUI。
- 默认风格为 Liquid Glass。
- UI 必须保持简洁直观。
- 不允许为了视觉效果牺牲性能。
- 所有长列表和大图表必须考虑懒加载。
- 允许在性能不足时切换到非 Liquid Glass 版本。

## 8. 架构要求

- MVVM 为唯一主架构。
- 数据存储使用 GRDB(SQLite) + Codable。
- JSON 仅用于导出。
- Repository 是唯一数据入口。
- View 不直接访问数据库。
- ViewModel 不做重型计算。
- Aggregation 在后台执行。
