# 目标用户群体与功能策略

> **日期**：2026-07-09

---

## 1. 三大人群画像

### 人群一：内容创作者 / KOL

**核心痛点**："我的内容值不值钱？品牌方凭什么投我？"

| 需求 | 当前状态 | 建议 |
|------|:--:|------|
| 粉丝增长分析 | ✅ Trends 已实现 | 强化：增加「增长来源分析」（哪篇帖子带来粉丝增长） |
| 互动率分析 | ✅ Trends + Premium Quality Score | 突出展示：互动率排名、互动率趋势预警 |
| 最佳发帖时间 | ✅ Decisions（Insight 卡片） | 增加：按星期+小时的互动热力图 |
| 竞品对比 | ❌ 未实现 | **Premium 新增**：同类账号均值对比（需第三方数据） |
| 粉丝活跃时段 | ⚠️ Decisions（Timing Profile） | 增加：24h 互动分布曲线 |
| 商业价值报告 | ❌ 未实现 | **Premium 新增**：一键生成「媒体包」PDF |

**定价策略**：免费版给 7 天趋势 + 3 张 Decisions 卡片；**Premium 解锁全部时间窗口 + 竞品对比 + 报告导出**。

---

### 人群二：品牌方 / 市场营销人员

**核心痛点**："我投的这个博主是不是真人粉丝？合作效果怎么样？"

| 需求 | 当前状态 | 建议 |
|------|:--:|------|
| 账号真实性评估 | ❌ 未实现 | **Premium 新增**：Engagement Quality Score + 粉丝增长异常检测 → 输出「真实性评分」 |
| 投放效果跟踪 | ❌ 未实现 | **Premium 新增**：自定义时间段对比（投放前 vs 投放后） |
| 多账号统一管理 | ✅ Settings 已有账号列表 | 强化：Dashboard 顶部横向切换多账号，每个账号独立数据 |
| 合作账号监控 | ❌ 未实现 | **第三方方案**：允许用户手动添加「监控账号」，本地抓取公开 followers_count + media_count 做趋势对比 |

**定价策略**：多账号管理 + 真实性评估 = **Premium 核心卖点**。这是 B2B 付费意愿最强的两个功能。

---

### 人群三：中小企业主

**核心痛点**："我没时间研究数据，告诉我今天该做什么。"

| 需求 | 当前状态 | 建议 |
|------|:--:|------|
| 简单数据看板 | ✅ Dashboard 已实现 | 保持：大号数字 + 箭头方向，一屏看完 |
| 评论回复 / 私信管理 | ❌ 未实现 | **新增**：Settings 中接入 Instagram Message API，App 内回复评论 |
| 内容排期 | ❌ 未实现 | **新增**：基于 Timing Profile 自动推荐未来 3 天的发帖时间 |
| 客户互动提醒 | ❌ 未实现 | **新增**：未回复评论超过 24h → Push 提醒 |
| 今天做什么 | ✅ Decisions 已实现 | 保持：Action Cards 直接告诉用户今天该做什么 |

**定价策略**：免费版给基础看板 + 3 张 Decisions 卡片；**Premium 解锁评论管理 + 内容排期**。

```
评论/私信管理       ❌               ✅
内容排期            ❌               ✅
多账号管理          ✅ 单账号        ✅ 3+ 账号 + 对比
真实性评估          ❌               ✅
媒体包导出          ❌               ✅
```
