# ADR-001：存储层方案

## 状态

已采纳

---

## 背景

本产品需要：

- 本地优先
- 支持时间序列分析
- 可维护
- 可扩展

的数据存储方案。

---

## 决策

采用：

- GRDB + SQLite 作为主存储
- Codable 作为序列化边界
- JSON 仅用于导入导出

---

## 影响

优点：

- 单数据库降低复杂度
- SQL 可精确控制索引与查询
- Event / Snapshot / Metric 共存于同一数据库

代价：

- Schema 修改必须编写 Migration
- 需要维护数据库版本

---

## 原因

本产品是分析型应用。

相比对象图管理：

- 查询能力
- 索引设计
- 时间序列分析

更重要。
