# 文档索引

本仓库使用以下核心文档：

- `AGENTS.md`：Agent 行为规则与硬性约束
- `ARCHITECTURE.md`：系统结构、架构分层与目录组织
- `docs/specs/alpha.md`：Alpha 版本范围与验收标准
- `docs/adr/`：架构决策记录（ADR）
- `docs/testing-strategy.md`：测试策略与质量门禁
- `docs/privacy-security.md`：隐私、本地存储与安全规范
- `docs/data-model.md`：标准数据模型说明
- `docs/roadmap.md`：产品路线图
- `docs/specs/premium.md`：Premium 功能扩展规范
- `docs/specs/instagram-oauth-login-plan.md`：Instagram OAuth 登录正式方案（域名 + AASA 回调）

## 文档放置原则

- 稳定且全局生效的规则 → `AGENTS.md`
- 描述系统结构与依赖关系 → `ARCHITECTURE.md`
- 描述某个具体功能 → `docs/specs/`
- 解释重大架构决策 → `docs/adr/`
