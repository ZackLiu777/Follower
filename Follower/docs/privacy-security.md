# 隐私与安全

## 数据策略

- 所有用户数据默认本地优先存储
- 默认不上传任何分析数据到云端
- 导出操作必须由用户主动触发
- 敏感 Token 不允许写入日志

---

## 存储规则

- 密钥和敏感信息使用加密存储
- 用户凭证与 Access Token 使用 Keychain
- 条件允许时启用数据库加密
- 导出文件必须与内部数据库隔离

---

## 用户权利

用户必须能够：

- 删除本地数据
- 撤销账号授权
- 查看本地存储内容

---

## 编码规则

禁止：

- 硬编码密钥
- 输出 Access Token
- 明文存储密码
- 未经允许同步用户数据
